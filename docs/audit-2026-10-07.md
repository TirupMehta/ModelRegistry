# Source audit - 2026-10-07

Auditor: ModelRegistry maintainers (automated link checks + manual source review).
Scope: all 49 models, 18 labs - every `links.*` URL (86 distinct), plus
replacement sourcing where links were dead.

## Method

1. Fetched all 86 distinct cited URLs (HEAD, then GET fallback, 15s timeout).
2. Re-fetched every HTTP 404 with a browser user-agent to rule out bot-blocking.
3. Read the replacement/primary pages for corrected records in full.
4. `verified` = core fields read and confirmed against live primary sources.
   `partially_verified` = >= 1 live official source; values transcribed at
   registration, per-field recheck scheduled. No record is `unverified` or
   `retired` after this audit.

Result: **verified 1, partially_verified 48, unverified 0, retired 0.**

## Unresolved uncertainties

- Registry benchmark figures (mmluPro / sweBench / terminalBench / gpqa /
  aime) are lab-published numbers transcribed at registration. They were NOT
  independently re-measured; per-model `fieldSources.benchmarks` is present
  only where a live announcement or model card plausibly carries them.
  Full per-field recheck is scheduled (see the maintenance plan on the
  `/methodology` page).
- Token-pricing precision for audio/per-second models uses the provider's
  headline rate converted to per-second billing; overage/enterprise tiers
  are out of scope.
- `help.aliyun.com` Model Studio page timed out to automation; content
  confirmed via search index. Cited with access note.
- Qwen3.8 Flash weights license terms: weights are published
  (Hugging Face / ModelScope) but the exact license text was not confirmed;
  `license` stays "Alibaba Cloud Model Studio", weights-license unverified.
- Pricing for weights-only models without a live pricing page
  (deepseek-v4-flash-vision-exp, meta-muse-spark-1-3, llama-4-*, 
  qwen-3-8-2-4t, mimo-v2-5/pro) has no citable official page; values kept as
  previously recorded, no pricing citation claimed.
